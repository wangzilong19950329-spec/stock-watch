# 继承限制（不是已整改声明）

当前版本同步了源仓库 `2f816607` 的 Stock Watch 实现，但不把测试通过解释为预测策略已被市场验证。

1. 预测复盘包含方向、区间、宽松方向和背离等展示口径；这些口径用于观察，不等于投资收益或可交易性证明。
2. M30 代码和分钟 Bar 接口已经同步，但 Compose 默认关闭 `STOCK_WATCH_M30_ENABLED` 和全部自动调度，需在真实 Bridge/行情联调后单独启用。
3. AI 观察条件仍包含业务关键词和固定阈值，不是通用 DSL。
4. 没有 Level-2、实盘下单、资金管理或被证明有效的策略样本库。
5. V6 引入了需求/任务/事实/预测及调度所有权状态，但独立容器默认单实例；没有把 Compose 验证扩展成多节点容灾证明。
6. 登录体系来自上游，Token 内存存储；容器重启会使会话失效，仅适用于单人本机或可信内网。
7. 邮件和告警投递仍依赖外部 SMTP；默认自动通知关闭，不宣称 exactly-once。
8. 实际 DeepSeek 登录、账号容量、模型质量和 SMTP 均依赖用户自己的外部状态，源码和单元测试无法证明其持续可用。
9. 独立容器默认连接本项目宿主机 8790 Bridge，不复用源项目 8791；不会复制 `.env`、密钥、Cookie 或浏览器 Profile。新专用 Profile 需人工登录，未配置认证 Key 时容器请求会失败。
10. 默认端口、数据卷和 Compose project 与源项目隔离，不迁移旧数据库、分析记录或用户。
