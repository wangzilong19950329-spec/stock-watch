# 继承限制（不是已整改声明）

这次只做源码拆分和独立运行所必需的适配，不实施此前规划的大重构。

1. `StockWatch.vue` 保留原页面的演示指标、示意价格线、硬编码运行描述；外层新增持续可见的警告。
2. `StockWatchTechnicalAnalysisService` 的宽松解析和 SUCCESS 语义保留；未实现 INVALID_OUTPUT/FactRef。
3. AI 观察条件中的关键词和固定阈值逻辑保留，未变成通用 DSL。
4. 未增加真实分钟 Bar、Level-2、样本库、双视角、风险期望或资金保护。
5. fixed-delay 与单进程防重入保留；未实现严格半小时槽位和多实例幂等。
6. 登录体系来自上游，Token 内存存储，注册可用，数据空间共享；仅用于单人本机/可信内网。
7. 邮件只有原有去重，未实现 Outbox 或 exactly-once；默认自动通知关闭。
8. 实际行情供应商、DeepSeek 网页/账号、API 模型、SMTP 未在无用户密钥条件下验证。
9. 保留 API 模型注册与搜索代码是为了维持观察规则依赖闭环；不保留会议/评分/工作流业务或模拟 AI 客户端。
10. 默认目录、端口、认证库与原项目隔离，不迁移旧数据库、历史分析、用户、Cookie 或个人浏览器 Profile。
